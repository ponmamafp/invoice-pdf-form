# 請求書PDF作成Webフォーム

外注先（個人事業主・フリーランス）が、スマホから最小入力で請求書PDFを生成・ダウンロードできる単一HTMLファイルのWebアプリです。

---

## 1. 特長

- **単一HTMLファイル** で完結（バックエンド不要・データはサーバーへ送信されません）
- **スマホ最適化**：iOS Safari / Android Chrome で快適に入力
- **国税庁ルール準拠の計算ロジック**：報酬+交通費を合算 → 税抜化 → 源泉徴収（10.21%、100万円超部分は20.42%）
- **インボイス対応**：税抜金額・消費税額を明確に区分してPDF出力
- **請求書No.自動採番**：`INV-0001` 形式の連番（localStorage管理・リセット可）
- **発行元情報はブラウザに保存**：1度入力すれば次回以降は入力不要

## 3. 使い方

### 初回セットアップ（外注さん本人が実施）

1. ブラウザで `index.html` を開く
2. 自動的に「設定」モーダルが開きます。以下を入力して **保存**：
   - **発行元情報**：氏名／会社名、インボイス登録番号、連絡先、住所（任意）
   - **宛先（請求先）**：会社名、担当者名
   - **振込先**：銀行名、支店名、口座種別、口座番号、口座名義
   - **支払条件**：支払期限（発行日から何日後か）
3. 設定はブラウザ内（localStorage）に保存され、次回以降は再入力不要

### 請求書を発行する

1. 画面で項目を入力
   - 発行日（デフォルト：本日）
   - 明細：内容＋金額（内税）のセット
     - 例：`2026年5月分 撮影費` / `12000`
     - **「＋ 明細を追加」** ボタンで複数行入力可（撮影 + 出張費 + 編集費 等を別々に明記したい場合）
     - 各行の **×** ボタンで削除可
   - 交通費（任意・源泉徴収の対象に含まれます）
2. 入力するとリアルタイムで計算プレビューが表示されます
3. 画面下部の **「PDFをダウンロード」** ボタンをタップ
4. `請求書_20260527_山田太郎.pdf` のような名前でPDFがダウンロードされます
5. 請求書No.は自動で +1 されます

### 設定の変更・リセット

- 画面右上の **「設定」** ボタンからいつでも編集できます
- 請求書No.は「連番リセット」ボタンで 1 に戻せます
- プレフィックス（`INV-`）と次回シーケンス番号は個別に編集できます

## 4. 計算ロジック（重要）

入力された金額は **内税（消費税10%込み）** として扱います。
源泉徴収は **税抜価格** に対して計算します（国税庁の正規ルールに準拠）。
交通費も **源泉徴収の対象に含めて** 計算します（外注立替分は実態が報酬と同じ扱い）。

```
合計税込金額      = 報酬金額（税込） + 交通費（税込）
税抜合計金額      = ROUNDDOWN(合計税込金額 ÷ 1.10, 0)
消費税額          = 合計税込金額 − 税抜合計金額

源泉徴収額（税抜合計 ≤ 100万円）
  = ROUNDDOWN(税抜合計 × 0.1021, 0)

源泉徴収額（税抜合計 > 100万円）
  = ROUNDDOWN(1,000,000 × 0.1021 + (税抜合計 − 1,000,000) × 0.2042, 0)

ご請求金額（振込額） = 合計税込金額 − 源泉徴収額
```

### 計算例

| 報酬（税込） | 交通費 | 税抜合計 | 消費税 | 源泉徴収 | ご請求金額 |
|---:|---:|---:|---:|---:|---:|
| ¥5,000 | ¥0 | ¥4,545 | ¥455 | ▲¥464 | **¥4,536** |
| ¥5,000 | ¥1,500 | ¥5,909 | ¥591 | ▲¥603 | **¥5,897** |

## 5. CONFIG（デフォルト値）の編集方法

通常は「設定」モーダルから編集すれば十分ですが、初期値（新しい端末で開いた時の値）を変えたい場合は `index.html` 冒頭の `<script>` 内 `CONFIG` オブジェクトを直接編集してください。

```javascript
const CONFIG = {
  issuer: {
    name: "氏名／会社名",
    registrationNo: "T1234567890123",
    contact: "メールアドレス／電話番号",
    address: ""
  },
  recipient: { ... },
  bank: { ... },
  consumptionTaxRate: 0.10,
  withholding: {
    standardRate: 0.1021,
    highRate: 0.2042,
    threshold: 1000000,
    label: "源泉徴収税額（10.21%）"
  },
  paymentDueDays: 30,
  invoiceNo: {
    prefix: "INV-",
    nextSeq: 1,
    padding: 4
  }
};
```

> ⚠️ 既にブラウザに保存済みの設定がある場合、`CONFIG` の変更は反映されません（localStorage の値が優先されます）。完全に初期化したい場合は、ブラウザのDevToolsで `localStorage.removeItem("invoiceFormSettings_v1")` を実行してください。

## 6. デプロイ手順

### Vercel

1. [Vercel](https://vercel.com/) にログイン
2. 「Add New Project」→「Import Git Repository」または「Upload」を選択
3. `index.html` と `README.md` を含むディレクトリをアップロード
4. デプロイ完了後、発行されたURLを外注さんに共有

### Netlify

1. [Netlify Drop](https://app.netlify.com/drop) を開く
2. `index.html` を含むフォルダをドラッグ＆ドロップ
3. 発行されたURLを共有

### GitHub Pages

1. GitHubで新規リポジトリを作成
2. `index.html` と `README.md` をプッシュ
3. リポジトリ設定 → Pages → Source: `main` ブランチ / `/ (root)` を選択
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開

> ヒント：URLをLINEなどで共有し、外注さんはスマホのブラウザから開いて「ホーム画面に追加」しておくと、アプリのように使えます。

## 7. 対応環境

- iOS Safari（iOS 15以上）
- Android Chrome（最新版）
- PC：Chrome / Edge / Safari / Firefox（最新版）
- ※IE 非対応

CDN（jsPDF / html2canvas / Google Fonts）への接続が必要なので、オンライン環境で利用してください。

---

## 8. プライバシー

- 入力したデータは **一切外部送信されません**
- 発行元情報・宛先・振込先・請求書No.の連番は、お使いのブラウザの localStorage にのみ保存されます
- ブラウザのキャッシュ／サイトデータを削除すると保存内容も消去されます

---

## 9. トラブルシューティング

**Q. PDFが文字化けする**
A. Noto Sans JP が読み込めていない可能性があります。オンライン環境で再度お試しください。

**Q. PDFのレイアウトが崩れる**
A. 内容欄が極端に長い場合に発生する可能性があります。改行で短く区切ってお試しください。

**Q. 「次回採番」を巻き戻したい**
A. 設定モーダル → 請求書No.の「次回シーケンス番号」を直接編集するか、「連番リセット」で 1 に戻せます。

**Q. PCで使うと文字サイズが大きい／小さい**
A. スマートフォン優先の設計です。PCで使う場合はブラウザのズーム機能で調整してください。
